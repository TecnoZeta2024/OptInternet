# Story 1.1: MSI Installer Readiness

## Status
Draft

## Story
**As a** Windows user with limited technical expertise,
**I want** to install OptiGemini through an MSI installer that validates prerequisites,
**so that** I can set up the desktop app without touching PowerShell scripts manually.

## Acceptance Criteria
1. The MSI installs successfully on Windows 10 21H2+ and Windows 11 23H2 without fatal errors.
2. The installer checks for required prerequisites (.NET Desktop Runtime 7.x, PowerShell 7.4) and presents clear remediation guidance if missing.
3. Uninstall removes application binaries, Start Menu entries, and cleans up `%APPDATA%/OptiGemini` while preserving user-created profiles backup.
