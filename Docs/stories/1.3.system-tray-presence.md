# Story 1.3: System Tray Presence

## Status
Draft

## Story
**As a** user who wants OptiGemini to run quietly in the background,
**I want** a persistent system tray icon with status summary and quick actions,
**so that** I can monitor connection health and reopen the app without keeping the main window visible.

## Acceptance Criteria
1. System tray icon reflects connection state (Optimal/Degraded/Offline) through iconography and tooltip text refreshed at ≤3 second cadence.
2. Double-clicking the tray icon restores the main dashboard window and focuses it in the foreground.
3. Tray context menu provides Start, Stop, Open Dashboard, Settings, Profile quick switch, and Exit options, honoring feature availability.
4. Tray interactions remain available when the main window is closed (app continues running in background), and application exit gracefully stops monitoring and disposes resources.
